#### Get started

Getting started has three steps, and you can do the first one in a few minutes.

1. **Install** Nishchay on your computer.
2. **Build your first resource.** The home page of your new application walks you through it, and so does [this tutorial](/learningCenter/getStarted/firstResource).
3. **Choose a path** from the ones below, depending on what you want to build.

Tell us a little about your setup and what you want to build. We will put together a reading path for you.

##### Paths after your first resource

Each path is a short list of pages to read in order.

###### Web application

1. [Build a web page](/learningCenter/getStarted/web): a controller, a route and a view.
2. [Views and templates](/learningCenter/request/viewTemplate): render pages with Twig.
3. [Request parameters](/learningCenter/request/requestParameter) and the [request store](/learningCenter/request/requestStore).
4. [Form builder](/learningCenter/security/formBuilder) and [CSRF protection](/learningCenter/security/CSRF).
5. [Sessions](/learningCenter/session).

###### REST API

1. [Write your own API route](/learningCenter/getStarted/restApi).
2. [Response handling](/learningCenter/request/responseHandling): JSON, XML or your own format.
3. [Web services](/learningCenter/service/webService): tokens, field filtering and custom responses.
4. [Route patterns](/learningCenter/request/routePattern): make the `Route` attribute optional.
5. [Validation](/learningCenter/security/validation).

###### Data

1. [Entities](/learningCenter/data/entity): the entity manager, properties and data types.
2. [Entity query](/learningCenter/data/entityQuery) and the [query builder](/learningCenter/data/queryBuilder).
3. [Database manager](/learningCenter/data/databaseManager): create and change tables from entities.
4. [Database settings](/learningCenter/settings/database): more than one connection.

###### Structure and tools

1. [Open structure](/learningCenter/openStructure): choose MVC, HMVC or your own layout.
2. [Containers](/learningCenter/container) and [dependency injection](/learningCenter/dependencyInjection).
3. [Prototype](/learningCenter/prototype): ready made implementations such as CRUD.
4. [Console commands](/learningCenter/consoleCommand): generate controllers, entities, forms and prototypes.
5. [Settings](/learningCenter/settings/application) and [environment variables](/learningCenter/environmentVariable).
